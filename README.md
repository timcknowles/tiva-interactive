# TIVA teaching interactives

Browser-based pharmacokinetic demos for TIVA teaching. Model predictions only; not for clinical use.

- `bolus-speed/` — propofol 2 mg/kg (adjustable) given at two rates; time to peak effect, Eleveld 2018 model.
  Live: https://timcknowles.github.io/tiva-interactive/bolus-speed/ (`?embed` for the compact slide view).
